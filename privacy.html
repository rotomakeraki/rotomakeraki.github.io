Privacy policy

Content Studio - last updated 25 November 2026

1. Who uses Content Studio

Content Studio is a private tool used by one person, its owner, to manage the owner's own videos and accounts. It runs on the owner's own computer. Nobody else can create an account or sign in, and it never acts on anyone else's account.

2. YouTube API Services

Content Studio uses YouTube API Services. By using Content Studio you are also using YouTube's services, so the YouTube Terms of Service apply, and the Google Privacy Policy describes how Google handles your data.

With the owner's permission, Content Studio uses YouTube API Services to:

  • upload the owner's videos to the owner's own channels and set their thumbnails;
  • create and update one public playlist per game on the owner's channel and add the owner's mission videos to it;
  • read the owner's channel name and ID, to find the owner's own channel;
  • read the owner's own channel statistics (views, watch time, subscribers, likes) from YouTube Analytics, to show charts and a weekly report to the owner only.

The gameplay that Content Studio edits is always the owner's own: recordings in the owner's own folders (on the computer or in Google Drive), or the owner's own uploads, which Content Studio downloads only from the owner's own channel to edit them into new videos for that same channel.

3. Other Google data

  • Google Drive: reads and writes files only in the owner's own "ContentStudio" folder (gameplay footage, finished videos and an encrypted backup). When a video goes to Threads, which only accepts a public link, that one file gets a temporary "anyone with the link" share that is removed as soon as Threads confirms.
  • Gmail: sends alert emails (security alerts, and a heads-up before an automatic post) from the owner's own address to the owner. Content Studio never reads, stores or deletes any email.

4. Meta (Facebook, Instagram, Threads) and other services

With the owner's permission, Content Studio posts the owner's videos to the owner's own Facebook Page, Instagram professional account and Threads profile, and reads their statistics (views, followers) to show them to the owner. Other services (X, Telegram, Dailymotion, Bluesky, Pinterest) are used only if the owner connects them, and only to post the owner's own videos.

5. AI writing services

To write titles, hooks and descriptions, Content Studio sends short text about a gameplay clip - and, only if the owner switches it on, a few still pictures from the owner's own gameplay - to free AI services (Google Gemini, Groq, OpenRouter, Cloudflare Workers AI). No sign-in tokens, account details or other personal data are sent. The free plans of these services may use what they receive to improve their services.

6. How data is stored and protected

Everything Content Studio keeps is stored on the owner's own computer. Sign-in tokens and keys are encrypted with a key that exists only in memory while the owner is signed in. Content Studio runs no server of its own that stores this data. Data is never sold, never shared for advertising and never used for anything other than the actions above.

Content Studio's own screens use sign-in cookies in the owner's browser to keep the owner signed in. There are no tracking or advertising cookies.

7. How long data is kept

  • YouTube statistics are kept only while they can be refreshed: the last 90 days, fetched again from YouTube on every run. They are deleted when the owner disconnects YouTube, or after 30 days if the YouTube sign-in stops working.
  • Records of published videos (their IDs and links) are kept so the same video is never published twice.
  • Statistics from other platforms are kept for up to 400 days to show trends to the owner.
  • Sign-in tokens are kept, encrypted, until the owner disconnects the account.

8. Sharing

Data goes only to the services the owner connected, and only to do what is described above. It is not shared with anyone else.

9. Removing access and deleting data

  • In Content Studio: Accounts → Disconnect deletes the stored sign-in (for YouTube, also the stored YouTube statistics).
  • Google: remove Content Studio's access at any time on the Google security settings page.
  • Facebook and Instagram: Facebook Settings & privacy → Settings → Apps and websites (or Business integrations) → remove Content Studio.
  • Deleting Content Studio's folder from the owner's computer deletes everything it stored.

More on the Delete your data page.

10. Google API Services User Data Policy

Content Studio's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

11. Changes and contact

When this policy changes, the date at the top changes. Questions: open an issue at github.com/rotomakeraki/rotomakeraki.github.io/issues.
